## **1. Classification using Gaussian Discriminant Analysis (GDA)**

### (a) 自行撰寫 GDA 演算法 (Do not use built-in classification functions)

我們透過一個名為 `MyQDA` 的自訂 Python 類別 (Class) 實現了二次判別分析 (Quadratic Discriminant Analysis, QDA) 演算法，全程未調用任何內建的分類函式。

- **`fit(self, X, y)` 方法**: 此方法負責模型的**訓練**。它接收訓練資料 `X`（特徵：經緯度）和 `y`（標籤：0 或 1），並計算出 QDA 模型的全部參數：
    1. **先驗機率 $ϕ_k$​ = P(y=k)**: 透過計算各類別樣本數佔總體比例得出。
    2. **類別平均向量 $μ_k​$**: 各類別資料點的均值，代表其分佈的中心。
    3. **類別共變異數矩陣 Σk​**: 各類別資料點的共變異數，描述其分佈的形狀與方向。QDA 假設每個類別擁有各自獨立的 Σk​。
        
- **`predict(self, X)` 方法**: 此方法負責模型的**預測**。對於一個新的資料點 `x`，它利用貝氏定理計算該點屬於每個類別的對數後驗機率 (log P(y=k∣x))，並將機率最高的類別作為最終的預測結果。
  
### (b) 模型原理與在本資料集的適用性

- **模型原理：**  
    GDA 是一種**生成學習演算法**。它不直接學習一條分隔線，而是試圖理解每個類別資料的內在分佈。其核心假設是：**來自同一個類別 k 的資料點，其特徵分佈服從一個多變量高斯分佈 $N(μ_k​,Σk​)$。在訓練階段，模型學習出每個類別的高斯分佈參數 ($μ_k​,Σ_k$​)。在預測階段，模型計算一個新點由哪個類別的高斯分佈「生成」的可能性最大，並以此進行分類。
    
    因為 QDA 允許每個類別擁有自己獨特的共變異數矩陣 $Σ_k$​，它能夠學習到不同形狀和方向的類別分佈，從而產生**二次曲線（如橢圓形）的決策邊界**。
    
- **適用性：**  
    - **有效觀測點 (label=1)** 集中於台灣本島，在二維座標上自然地形成了一個類似橢圓的群集。
    - **無效觀測點 (label=0)** 則散佈在周圍的海洋區域。 
    
    QDA 的二次決策邊界能夠非常靈活地擬合台灣島不規則的橢圓輪廓，比線性判別分析 (LDA) 的直線邊界更具優勢，因此能夠更準確地劃分陸地區域與海洋區域。

### (c) 模型訓練與性能評估

我們採用了標準的機器學習評估流程：將資料集以 80/20 的比例隨機分割為**訓練集**與**測試集**。模型僅在訓練集上學習，其最終性能則在從未見過的測試集上進行評估。

- **分類訓練集大小**: (6432, 2), **測試集大小**: (1608, 2)
- **Train Loss (NLL)**: 2.1291
- **Test Loss (NLL)**: 2.1576
- **QDA Test Accuracy**: **82.52%**

**結果分析**: 測試集準確率達到 82.52%，證明模型具有不錯的分類能力。更關鍵的是，**測試集的損失 (2.1576) 與訓練集的損失 (2.1291) 非常接近**，這表明我們的模型具有良好的泛化能力，**並未發生過擬合**。

## **2. Regression — Piecewise Smooth Function**

### (a) 程式碼實作分段迴歸模型

我們成功地實現了作業中定義的分段函數 h(x)。此實現包含兩個核心部分：

1. **迴歸模型 R(x)**: 我們建立了一個自訂的 `MyPolynomialRegressor` 類別來實現**二次多項式迴歸**。該模型的權重參數 θ 是透過**正規方程 (Normal Equation)** 的封閉解直接計算得出，無需迭代優化。
    
2. **組合函數 `combined_model`**: 此函式是分段邏輯的核心。它首先調用已訓練好的 QDA 分類器 C(x) 進行判斷。然後，利用 `np.where` 函式，如果一個點被分類為 1，則調用迴歸器 R(x) 輸出預測值；如果被分類為 0，則直接輸出 -999。

### (c) 組合函數的設計說明

組合函數 `h(x)` 的建構流程如下：
1. **第一步：分類判斷**。利用先前訓練好的 QDA 分類器 `C(x)`，判斷輸入的地理座標點是位於「有效區域 (label=1)」還是「無效區域 (label=0)」。
    
2. **第二步：條件預測**。根據上一步的分類結果執行條件分支：
    - 若判斷為**有效區域**，則將該座標點交給二次多項式迴歸器 `R(x)`，計算出一個連續的預測數值（如溫度）。
    - 若判斷為**無效區域**，則直接指定輸出值為 **-999**。

透過這個兩步流程，我們成功地將一個分類模型和一個迴歸模型整合成一個單一的、具有分段行為的複合預測函數。
