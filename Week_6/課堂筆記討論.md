
### 討論其他神經網絡表示函數

ex1 : 絕對值函數 `f(x) = |x|`，它在 x=0 處不可微分。

我們可以使用一個非常簡單的神經網路，利用 **ReLU** (Rectified Linear Unit) 激活函數來建構它。ReLU 函數的定義是 `ReLU(x) = max(0, x)`。

則 $f(x) = ReLU(x) + ReLU(-x)$

ex2 : 表示階梯函數 (Heaviside Step Function)

標準的階梯函數在 x < 0 時為 0，在 x > 0 時為 1。我們可以用 Sigmoid 或 Tanh 函數來近似它。

Sigmoid 函數 $σ(x) = 1 / (1 + e⁻ˣ)$ 的形狀很像一個平滑的階梯。當考慮函數 `f(x) = σ(kx)`。k是一個非常大的正數時，則會其變得非常陡峭，從而近似一個理想的階梯函數。

所以，H(x) = σ(wx)` 可以用來近似一個階梯函數。`w` 的值越大，近似效果越好。

Q:試著討論能不能造出脈衝函數(Dirac Delta Function)

定義:
- 在 x=0 時，其值為無窮大。
- 在所有其他 x ≠0 的地方，其值為 0。
- 其在整個實數線上的積分為 1。

方向一 : 利用極窄的方波函數，$$N(x)=\frac{1}{2ϵ}​[σ(k(x+ϵ))−σ(k(x−ϵ))]$$

方向二：利用極尖的高斯函數，
$$
g(x,σ) = \frac{1}{σ(2\pi)^{1/2}} \exp[-\frac{x^{2}}{2σ^{2}}]
$$
這個函數的總積分恆為 1。當我們讓標準差 σ 趨近於 0 時：

- 函數的寬度會變得極度窄。
    
- 函數在 x=0 處的高度會趨近於無窮大。
